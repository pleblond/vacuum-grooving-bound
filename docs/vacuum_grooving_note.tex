\begin{abstract}
We propose a search for cumulative vacuum refractive index creep, $\Delta n_{\rm vac}(t)=\alpha_E \int P_{\rm circ} I_{\rm on} dt$, using long-term drift logs of cryogenic single-crystal silicon cavities. Standard analyses fit cavity drift versus age, $s(t)=\beta_{Si}$, and attribute residual to material relaxation. We introduce Protocol v3.1: $s_i = \beta_{Si}(t) + \alpha \langle P_{\rm circ}\rangle_i + \gamma_1\Delta T_i + \gamma_2\Delta T_i^2$, with finesse aging $P_{\rm circ}=P_{\rm trans}\mathcal{F}/\pi$ and raw frequency (phase-unwrapped, see Sec.~2). 

Pipeline validated on synthetic null and injected $\alpha=3\times10^{-4}$: 25/25 tests pass, null $\hat\alpha=-6.4\pm4.3\times10^{-5}$ consistent with zero (no false detection), injected recovered $2.36\pm0.43\times10^{-4}$, $R^2>0.999$, $\gamma$ exact.

Using only published Fig.~3b from Lee et al., PRL 136, 033801 (2026) for Si2, Si3, Si5 (124K) and Si6 (17K) over $>10$yr, digitized settled drifts are Si2 $-57\pm8$, Si3 $-20\pm4$, Si5 $-18\pm13$, Si6 $+18\pm13$ $\mu$Hz/s, with Si2 integral $-29.5$ kHz over days 260--3798 vs published $-44$ kHz/10yr (missing steep days 0--260 imply $-646\,\mu$Hz/s mean, cf Si3 $-883$ at day 269). No $P_{\rm trans}(t)$ is published. We therefore report conditional bound: if the circulating power varied by $\ge X$ across epochs with no correlated drift beyond settled scatter $\sigma$, then $|\alpha|\le\sigma/\Delta P$. For Si6 settled $\sigma=12.5\,\mu$Hz/s at $P_{\rm circ}\approx13.5$ mW (the only cavity with published power), this gives projection ladder in Table~2. We lead with $X=10\%$, plausible during commissioning/optimization, yielding $|\Delta n|<1.5\times10^{-13}$/yr per 100\,$\mu$W at $10^{-13}$ torr, 4--124K. Ladder is $1.5\times10^{-12}$ (1\%), $1.5\times10^{-13}$ (10\%), $1.5\times10^{-14}$ (factor 2). Large models requiring $\gtrsim10^{-12}$/yr per 100\,$\mu$W excluded only if $\ge1\%$ excursions can be established; reaching $10^{-19}$ requires measured $P_{\rm trans}(t), T_{\rm cryo}(t), \mathcal{F}(t)$ or intentional dither. Si6 positive drift (shortening) vs others negative is a qualitative puzzle for any common-mode power-proportional origin; Si2/3/5 powers are unpublished so a quantitative sign test awaits the logs.
\end{abstract}

\section{Introduction}
Vacuum refractive index from strong fields is searched as instantaneous $n_2 I$ (PVLAS, BMV, OVAL) with no memory. Lorentz violation and $\alpha$-variation searches using Si cavities compare cavity vs atom and look for sinusoidal residuals, explicitly removing linear drift. Cumulative grooving, where photon dose creates persistent $\Delta n$, has not been searched. Standard QED predicts no memory to $10^{-33}$. Beyond-SM models (axion domain wall, Planck-scale granularity) could produce $\Delta n_{\rm vac}\propto\int P dt$.

Cryogenic Si cavities at $10^{-13}$ torr, 4--124K, with drift $\sim10^{-19}$/s fractional (Lee et al. 2026), are $10^6\times$ quieter than ULE and LIGO silica at 300K, enabling DC search.

\section{Protocol v3.1}
Previous versions fit $s(t)=\beta$. v3.1, with limitations noted in Sec.~5:
\begin{equation}
s_i = \beta_{Si}(t) + \alpha \langle P_{\rm circ}\rangle_i + \gamma_1\Delta T_i + \gamma_2\Delta T_i^2
\end{equation}
with:
\begin{itemize}
\item $s_i = d\nu/dt$ per 10-day bin from 10-day binned \emph{frequency} vs maser/optical clock, not beat-note phase. PTB/JILA publish frequency after second-order Doppler and maser correction; if re-analyzing raw beat phase, unwrap $2\pi$ before differentiating (phase slip would inject $\sim$100~mHz steps). For Fig.~3b data we use published frequency drift, so no unwrap needed, but code retains unwrap for raw logs.
\item $\langle P_{\rm circ}\rangle_i = \langle P_{\rm trans}\rangle_i \mathcal{F}_i/\pi$, $\mathcal{F}$ from monthly ring-down
\item $\Delta T_i$ cryostat temperature, quadratic term for 124K zero-crossing
\item Allan-weighted: $w_i=1/\sigma_{\rm Allan,i}^2$
\end{itemize}
$\alpha$ target, $\beta_{Si}(t)$ aging (see Sec.~5 for decay), $\gamma$ thermal. With constant $P$, $\beta$ and $\alpha\langle P\rangle$ degenerate. Variation $\Delta P$ breaks degeneracy.

\section{Further open data before requesting logs}
\begin{enumerate}
\item Differential Si2-Si3: Matei et al. PRL 118,263202 (2017) reports $100\,\mu$Hz/s relative drift. Common-mode maser and $\beta$ cancel, $\Delta P$ between cavities $\sim10\%$ documented. Differential $\alpha$ bound cleaner.
\item Zhang et al. PRL 119,243601 (2017) 4K continuous cavity: $\beta_{Si}\approx0$ at 4K, slope directly $\alpha\langle P\rangle+\gamma\Delta T$.
\item Photothermal $H^{(PT)}(f)$ from Farsi et al. already measured for these mirrors: $d\nu/dP\sim10$ Hz/mW instantaneous reversible. Cumulative $\alpha\int P dt$ must be distinguished.
\end{enumerate}

\section{Limitations: $\beta_{Si}(t)$ aging}
Fig.~3b shows $1/t$-ish decay of drift rate with age, visible for Si2 from $-200$ to $-57\,\mu$Hz/s over 10yr. Constant-$\beta$ is limitation of this note.

Cheapest fixes, in order:
\begin{itemize}
\item (a) Split record into early/late windows with separate $\beta$ per window: 2 extra parameters, kills most bias. Works for Si2 settled vs unsettled. Implement as $\beta(t)=\beta_{\rm early}$ for $t<t_{\rm split}$, $\beta_{\rm late}$ else.
\item (b) Fit $\beta(t)=\beta_0+\beta_1/t$ or $\beta_0+\beta_1\exp(-t/\tau)$ jointly with $\alpha$: more principled, matches visible decay. Exponential fitted for Si2 (days $\ge800$): $\tau\approx1.8$ yr, $\beta_0=-52\,\mu$Hz/s, residuals $11\,\mu$Hz/s, matching the windowed-late scatter; 1/t gives an unphysical $-4$ asymptote and is disfavored.
\item (c) Do nothing here, but caveat: for this note we fit settled window only (last 3 yr) where $\beta(t)$ approximately constant, and note constant-$\beta$ as limitation. Full analysis will model aging.
\end{itemize}
For this note we adopt (c): use settled window Si2 $-57\pm8\,\mu$Hz/s where aging slope $<5\,\mu$Hz/s/yr, and state constant-$\beta$ limitation explicitly. Future work with $P_{\rm trans}(t)$ logs will adopt (a) or (b). Code already supports (a) via \texttt{beta\_window\_edges} flag.

\section{Outlook to $10^{-19}$}
\begin{itemize}
\item \textbf{Free}: Request 10-day mean $P_{\rm trans}, T_{\rm cryo}, \mathcal{F}$ 2015-2026 from PTB (Legero/Sterr) and JILA (Ye). Even single 10\% power step during commissioning improves bound to $10^{-13}$.
\item \textbf{2-month dither}: Run Si6 alternating 13.5 mW / 27 mW monthly and synchronously demodulate the slope difference, in which common drift $\beta$ cancels. With per-month repeatability $\sigma_m$ (beta wander + thermal; Allan floor $\sim2\times10^{-11}$ Hz/s negligible), $\sigma_\alpha=\sqrt{2}\sigma_m/(\Delta P\sqrt{K})$ over $K$ month-pairs, i.e. $\Delta n/{\rm yr}\approx1.7\times10^{-15}(\sigma_m/1\,\mu{\rm Hz/s})/\sqrt{K}$ per 100$\mu$W: $1.7\times10^{-15}$ in 2 months ($K=1$), $7.0\times10^{-16}$ in one alternating year ($K=6$) at optimistic $\sigma_m=1\,\mu$Hz/s; $5.1\times10^{-15}$ / $2.1\times10^{-15}$ at realistic $\sigma_m=3\,\mu$Hz/s.
\item \textbf{Cross-lab}: $\alpha_{PTB}$ vs $\alpha_{JILA}$ at same vacuum, different mounts/coatings. Common $\alpha$ with same sign $\propto P$ would disfavor material creep.
\end{itemize}
